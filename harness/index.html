  5. Right-click DC01 in DeviceName → Machine must be.
  6. Right-click svc-sql in AccountUpn → Account, not Machine.
  7. Pick a rule → KQL lands in the fake editor below.
  8. Search the rule list, use ↑/↓ and Enter, try the ±1h/±24h/±7d presets.
  9. Settings → Clients, Threat Intel, Capture storage, Migration all render.
  10. Switch the browser to French/English and reload — labels follow.
